주니어 백엔드 개발자로 입사 지원용 포트폴리오 프로젝트를 진행 중.
Spring Boot / Java 실력을 보유하며, DDD / 멀티모듈 / 분산 시스템 개념을 익히는 과정.
기술 깊이(성능 측정, 아키텍처 결정)를 중시하며 포트폴리오 완성도에 집중.

선호하는 작업 방식:
- 핸드오프 문서를 통한 세션 간 컨텍스트 유지
- 세션 시작 시 문서를 읽고 현황 파악 후 작업 계속
- 브랜치 전략: feature/performance 하나에 모든 작업 축적 (빅 PR 전략)
- 의사결정 분기점마다 decisions/ 자동 기록 (묻지 않고 자동)
- 포트폴리오 문서(ADR, troubleshooting) 자동 갱신
